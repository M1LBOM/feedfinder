FeedFinder Studio

Privacy Policy

Last updated: 24 September 2026

YouTube API Services

FeedFinder Studio uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Whose data it touches

Only the data of the person who runs it, about the YouTube channels they own and have signed in with. FeedFinder Studio has no other users. It collects nothing about viewers or anyone else.

What it accesses, and why

  • The signed-in channel's identity (channel ID), to confirm which channel it is posting to.
  • Uploading, scheduling and deleting the channel's own videos, to post the owner's finished videos and to withdraw one the owner vetoes.
  • The channel's own videos' statistics and analytics (views, engaged views, watch percentage, likes, comments count), to learn which videos people enjoy.
  • Comments on the channel's own videos, to post one credit comment per video and to notice a creator asking for their clip to be removed.

It never searches YouTube, never reads other channels or their videos, and never downloads anything from YouTube.

Where the data is kept

On the owner's own computer, in a local database, and nowhere else. It is not sent to any server, not shared with or sold to anyone, and not used for advertising. The sign-in token is stored in a local file that only that computer can read.

How long it is kept

Statistics about the channel's own videos are refreshed as they are read and kept only to compare videos with each other. The owner can delete any or all of it at any time by deleting the local database. No data obtained from YouTube about anyone else is stored.

Revoking access

Access can be withdrawn at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After that FeedFinder Studio can no longer read or post anything, and its stored token stops working.

Cookies and tracking

FeedFinder Studio is a desktop program. It sets no cookies and does not track anyone. This website sets none either.
